# Rent-a-Ruckus Play

Published browser build of the multiplayer 3D property game.

Game: https://time-machine-lab.github.io/Rent-a-Ruckus-Play/

This repository contains public web assets only. The development source repository remains private. Server credentials and player data are not stored here. The bundled Supabase anon key is intentionally public; game state is protected by the server-side API and database access controls.
